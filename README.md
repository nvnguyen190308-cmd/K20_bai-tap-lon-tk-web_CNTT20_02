# PawCare DNU – Website Dịch vụ Chăm sóc Động vật (FIT4014 · A3)

Website tĩnh HTML5/CSS3 giới thiệu dịch vụ chăm sóc động vật (khám sức khỏe định kỳ, tiêm phòng – tẩy ký sinh trùng, spa/grooming, lưu trú chăm sóc và đặt lịch tư vấn).

## Cấu trúc thư mục
- `index.html`: Trang chủ giới thiệu dịch vụ, bảng gói tham khảo, quy trình tiếp nhận và biểu mẫu đặt lịch.
- `chi-tiet-dich-vu.html`: Trang mô tả chi tiết từng nhóm dịch vụ và lưu ý chuẩn bị.
- `css/style.css`: Định dạng bố cục Grid/Flexbox, biến màu và media queries responsive.
- `images/`: Hình ảnh minh họa SVG cho các nhóm dịch vụ.

## Cách mở và chạy
1. Tải hoặc clone repository về máy tính.
2. Mở trực tiếp `index.html` bằng trình duyệt web (Chrome, Edge, Firefox) hoặc chạy qua Live Server / GitHub Pages.

## Giới hạn
- Là website tĩnh front-end, chưa tích hợp cơ sở dữ liệu lưu lịch đặt khám/spa thực tế hoặc gửi thông báo tự động.
